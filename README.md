# 주인님 비서실 · Daisy Office

주인님 전용 비서실 웹앱. 데이지 모티프(매트 블랙 + 화이트 페탈 + `#F5B800` 꽃술)의 단일 파일 정적 웹앱입니다.

**Live:** https://cv67d7hy4w-cloud.github.io/SEI/

## 구성

- **회의실** — 3개 방(🏛️ 대회의실 / 🎯 지휘실 / ☕ 라운지), 발신자 칩 5명, `@all`·`@피클`·`@덕질비서`·`@예약비서`·`@쇼핑비서` 원터치 멘션, 멘션된 비서의 0.5초 자동 응답(설정에서 토글)
- **작업실** — 작업 추가·상태 전환(대기/진행/완료)·삭제(실행 취소 지원), 상태 필터
- **비서현황** — 비서 4명 카드, 담당 업무, 맡은 작업 수와 진행 상태
- **메모** — 추가·편집·삭제

모든 데이터는 브라우저 `localStorage`(`seiOffice.v1`)에만 저장됩니다. 서버·계정·추적 없음.

## 배포

`index.html` 단일 파일. GitHub Pages(`main` / `/`)로 서빙됩니다.
